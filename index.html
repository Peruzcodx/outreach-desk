Workspace configuration

Account settings

Assign each lead to the correct mailbox label.

Gmail account mapping

Enter the exact email address for each Gmail account. When you open a draft, Outreach Desk will ask Gmail to open using the assigned address. You must already be signed in to that Gmail account in the browser; check the From address before sending.


Backup and recovery

Lead records and Gmail labels are stored in this browser only. Download a full backup before replacing the app or changing devices. The backup includes lead records, reply-tracking fields, and account labels; it does not include Gmail passwords or OAuth tokens.

Restoring a backup replaces the current records in this browser. Export your current data first if you may need it.

Import rules

Use a UTF-8 CSV with one lead per row. Keep the header names from the template. Personalized email subject, email body, and follow-up message fields are imported into editable fields.

Reply tracking and integration

The Replies page currently tracks replies that you record manually. Automatic detection across your Gmail accounts will need secure Google OAuth authorization, Gmail API access, and a backend service to sync messages. Do not store passwords in this app.

Prototype boundaries

Lead data is stored in this browser's local storage. There is no shared database, automatic background research, verified Gmail OAuth connection, automatic reply synchronization, or real bulk sending in this phase.
